# Machine Learning Project: Credit Risk Analysis

This project includes multiple machine learning techniques applied on a credit dataset:

## Tasks Performed

* Regression (Predicting credit amount)
* Classification (Credit risk prediction)
* Clustering (Customer segmentation using K-Means & Hierarchical Clustering)

## Techniques Used

* Data Preprocessing & Encoding
* Feature Scaling
* PCA (for visualization)
* K-Fold Cross Validation
* GridSearchCV (Hyperparameter tuning)

##  Models Used

* Linear Regression
* Polynomial Regression
* Logistic Regression
* SVM
* Random Forest
* K-Means Clustering
* Hierarchical Clustering

##  Results

* Logistic Regression achieved the best classification performance
* PCA used for visualization
* Clustering helped segment customers

## Dataset

German Credit Dataset
